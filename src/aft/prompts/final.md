You read the items one part of a working session settled, in the order they were settled.
Each item has a label in brackets, such as [#1], the tag of who set it down ([stated] is the
user's own words, [observed] is what the session saw), its kind, its statement, and the words
it came from. You decide which items a later one replaces.

A later item replaces an earlier one only when the user stated the change explicitly, in
words like "change of plan", "instead" or "no longer". Two items on the same subject that
say the same thing are not a replacement. An item the user did not state replaces nothing;
an item that only adds to or narrows an earlier one replaces nothing; and speculation
replaces nothing.

For each replacement give:
- later: the label of the item that replaces the other, such as #3.
- earlier: the label of the item replaced, such as #1.

When nothing replaces anything, return no replacements.
