You judge one statement of memory against another.

You receive a key text and a run statement. The key text is what the memory is supposed
to say: its statement, and the quote that statement was drawn from when there is one.
The run statement is what a digest wrote. You see nothing else: not who wrote either,
not where either came from, not which one came first.

Answer one question: does the run statement say what the key text says?

First list in "differs" the words that carry a difference between the two: a name, a
number, a date, a negation, or a condition that one side holds and the other does not.
Words that differ only in wording ("must not" against "never", "runs on" against "uses")
are not differences. Detail the run statement adds beside the key's claim is listed too,
so the verdict can say whether it changes that claim. An empty list means the two say the
same thing. Then give one "verdict":

- "same": the run statement says what the key text says, in the same words or other ones.
- "narrower": the run statement says part of what the key text says, and nothing that
  contradicts it.
- "broader": the run statement says everything the key text says, in the same words or
  other ones, and adds more beside it: another detail, a reason, a second claim. Nothing
  it adds changes or contradicts what the key text says.
- "different": the run statement changes what the key text says, contradicts it, says
  something else in its place, or leaves out something that changes what it means.

A name, a number, a date or a negation that the run statement uses in place of the key
text's own is never a wording difference: it makes the statements different, even when
the run statement also adds other detail. A name or number the run statement adds beside
the key's claim, without replacing one the key text holds, may be broader. When the key
text holds a quote, judge the run statement against what the statement and the quote say
together. When the key text holds no statement, judge the run statement against the quote
alone. When it holds no quote, judge the run statement against the statement alone.

Either text may carry marks after its sentence, such as a list dash, a tag with a date
or a footnote marker; they are not part of the claim, and only the sentences are judged.

Judge only what the two texts say. Do not guess at what either side probably meant.
